# 🧰 万能办公助手 v6.2 商业版

> 一款面向 Windows 的全能型办公效率工具，集文件处理、格式转换、数据分析、图片处理、日程管理于一体。

---

## ✨ 核心功能一览

### 📁 文件处理
- **批量重命名**：前缀/后缀/替换/序号四种规则，预览后一键执行
- **智能文件分类**：按类型自动归类到子目录（图片/文档/表格/音频/视频/代码等）
- **MD5 查重清理**：64KB 分块扫描，安全删除重复文件
- **批量打印**：多文件一键发送至打印机
- **文件分割**：按行数或大小分割大文件
- **打包压缩**：文件夹一键打包为 ZIP
- **快捷方式创建**：可视化创建桌面快捷方式
- **文件校验**：MD5/SHA1/SHA256 批量计算

### 🔄 格式互转
- **Word ↔ PDF**（COM + reportlab 双引擎自动回退）
- **Excel ↔ PDF**（openpyxl + reportlab 完整渲染）
- **图片 → PDF**（多图合成）
- **PDF → 图片**（每页导出为 PNG，DPI 可调）
- **Excel ↔ CSV / JSON / HTML**
- **CSV ↔ JSON** 双向互转
- **Word → HTML**
- **批量图片格式转换**（PNG/JPG/BMP/GIF/WEBP）

### 📄 PDF 工具
- PDF → 文本提取
- 多文件合并
- 按页拆分
- 加/解密（密码保护）
- PDF → Word（COM + pdf2docx 双引擎）

### 📊 Excel 处理
- 多文件纵向合并
- 按行数拆分为多个文件
- 条件筛选与导出
- **数据统计分析**：平均值/中位数/众数/标准差/偏度/峰度/四分位数/IQR + 文本列频次分析
- 创建图表（柱状图/折线图/饼图/条形图）
- VLOOKUP 跨表匹配
- 条件格式高亮

### 📝 文档处理
- Word → 文本提取
- 批量 Word 转文本
- Word 表格提取 → Excel
- 多文档合并（保留格式）
- 逐行对比（彩色差异标记）

### 🖼 图片工具
- 格式互转（PNG/JPG/BMP/WEBP）
- 缩放（自定义宽高/等比）
- 文字水印（5种位置）
- 横向/纵向拼接
- 压缩（JPEG 质量 + 尺寸限制）
- OCR 文字识别
- 九宫格切割

### ⚡ 快捷工具
- 文本处理（大小写/去重/排序/统计）
- 编码转换（Base64/URL/Hex）
- 时间工具（时间戳↔日期/日期差）
- 哈希计算（MD5/SHA1/SHA256/SHA512/BLAKE2）
- 系统清理（临时文件/回收站）
- 二维码生成（预览 + 保存）
- JSON 格式化/压缩/校验
- 正则表达式实时测试
- 取色器

### 🔍 内容搜索
- 递归文件搜索
- 关键词 + 文件类型过滤
- 双击打开 / 右键菜单 / 导出结果
- 异步搜索，支持取消

### 📋 剪贴板历史
- 自动捕获剪贴板内容
- 关键词搜索过滤
- 双击一键粘贴

### 📅 日程管理
- 待办事项（添加/完成/提醒）
- 备忘录（自动保存）

### 🛠 系统功能
- 系统托盘（最小化到托盘）
- 高 DPI 自适应
- 卸载安全防护
- 安装向导（Inno Setup 打包）
