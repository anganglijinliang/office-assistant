万能办公助手 v6.1 商业版
========================

一个全能的Windows办公工具，支持格式互转、PDF处理、文档处理、图片处理等57+功能。

## 功能特色

- 📁 文件处理：批量重命名、智能分类、MD5查重
- 📊 Excel处理：合并/拆分/筛选/统计/图表
- 📝 文档处理：Word提取/表格/合并/对比
- 📄 PDF工具：提取文本/合并/拆分/加密/解密
- 🖼 图片工具：格式转换/缩放/水印/拼接/压缩/OCR/九宫格
- 🔄 格式互转：Word↔PDF、Excel↔PDF、图片↔PDF、CSV↔JSON↔Excel
- ⚡ 快捷工具：文本处理/编码转换/时间工具/哈希计算
- 📋 剪贴板管理：自动捕获、历史回溯
- 🔍 文件内容搜索：按关键词+类型递归搜索（可取消）
- 📅 日程管理：待办事项+备忘录（自动保存）

## 安装说明

### 快速安装（推荐）
1. 直接运行 `万能办公助手v6.1商业版.exe`
2. 无需安装，即点即用

### 从源码运行
```bash
pip install -r requirements.txt
python office_assistant.py
```
